# Kazuma Port Games BR — Identidade visual planejada para PS4

## Decisao do projeto (22/10/2026)
Usar **a arte original enviada como base** e assinar como **Kazuma Port Games BR** de maneira discreta e identificavel, preservando os creditos dos criadores do jogo.

### Primeiro PKG de teste que tiver uma interface visual
- Incluir identificacao legivel `Kazuma Port Games BR — port nao oficial para PS4` na tela propria do homebrew / splash de teste, alem do `PIC1.PNG` (banner), se os meios tecnicos permitirem.
- Preferir os elementos visuais originais do jogo sem apagar direitos autorais, marcas originais ou creditos.
- Se for apenas um **PKG de diagnostico** que ainda nao carrega a interface do jogo, **nao alegar** que a logo foi embutida no menu do jogo. Registrar isso como pendente.

### Quando o menu do jogo estiver acessivel e modificavel
- Assinatura discreta no canto inferior do menu principal.
- Credito em tela de titulo: `Port PS4 nao oficial: Kazuma Port Games BR`.
- Creditos ou tela de informacoes com responsabilidades e atribuicoes corretas, inclusive autores originais, traducoes de terceiros usadas com permissao e colaboradores.
- Banner do PKG como identidade complementar, nunca unica.

### Integridade e atribuicao
- Nao existe marca impossivel de remover em arquivos controlados por terceiros. O melhor respaldo e historico de commits, notas de versao e licencas / atribuicoes corretas.
- Nao modificar a apresentacao original para sugerir apoio ou desenvolvimento oficial do port pelos titulares.
- Nao incluir nem publicar recursos comerciais ou arquivos de jogo no repositorio do runtime.
- Nenhum visual novo e criado nesta etapa de diagnostico; aplicar estes itens quando o pipeline suportar.
